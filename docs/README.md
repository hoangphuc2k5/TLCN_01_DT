# Tài liệu dự án

- `architecture/`: kiến trúc và quy ước tổ chức mã nguồn.
- `deployment/`: CI/CD, backup, file storage, job queue và cấu hình tích hợp.
- `features/`: đặc tả và ghi chú theo chức năng nghiệp vụ.
- `planning/`: kế hoạch triển khai và lịch sử tiến độ.
- `quality/`: QA, review, regression và checklist sẵn sàng demo.

Tài liệu mới cần được đặt theo mục đích sử dụng thay vì theo thời điểm tạo.

Xem [cấu trúc repository](architecture/project-structure.md) để biết trách nhiệm của từng thư mục.
